# Support

Use the SearchStax customer support portal at
https://www.searchstax.com/support/ for product questions, configuration help,
and compatibility questions.

This repository does not promise GitHub Issues as a product-support channel,
response times, availability commitments, or an SLA. Include the public image
version or commit, image digest when applicable, schema status, deployment
profile, timestamps, and redacted error category in a support request. Never
send credentials, tokens, database dumps, article content, or full environment
output.
